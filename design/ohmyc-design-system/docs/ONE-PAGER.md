# ohmyc — 해커톤 ONE-PAGER

## 한 줄 정의
**ohmyc는 대중의 첫 캐릭터 에이전트.** 단순 채팅이 아닌 "기억·행동·성장"하는 페어(Pair)를 만나는 모바일 웹앱.

## 핵심 슬로건 (네티 IR 공식)
> "오픈클로가 개발자에게 '나만의 AI 에이전트'를 줬다면,
> ohmyc는 대중에게 '나만의 캐릭터 에이전트'를 준다."

→ 에이전트 시대, **대중의 첫 에이전트는 캐릭터다.**

## 타깃
글로벌 20-30대 여성. 캐릭터/IP 친화, AI 컴패니언 수요.

## 문제
- **ChatGPT**: 도구적 관계, 누적되지 않음
- **Character.AI**: 채팅만, 에이전트가 아님 (행동 못 함)
- **Replika**: 1:1 한정, 마켓플레이스 부재
- **갭**: "나를 아는 캐릭터"가 "나를 위해 행동"하지 못함

## 해결책 (Phase 1 MVP — "페어 첫 만남" 데모)

1. **인트로**: 타이핑 효과 — *"이야기 속에서만 만나던 캐릭터, 이제 당신의 페어가 되어 곁에 있어요"*
2. **캐릭터 선택**: 프리셋 1명 (또는 이름 입력)
3. **페어링**: `[페어링하기]` 버튼 → Pulse 모션 → 채팅방 진입
4. **선제 발화**: 캐릭터 — *"안녕! 우선 오늘 네가 꼭 해야 할 일 하나만 알려줄래?"*
5. **행동 약속**: 유저 입력 → 캐릭터 — *"알았어, 3시간 뒤에 다 했는지 내가 꼭 물어볼게!"*
6. **기분 트래커**: *"지금 기분은 좀 어때?"* → 이모지 → 맞춤 공감 응답

## 차별점

| | 기존 | ohmyc |
|---|---|---|

## 기술 제약 (Phase 1 stack)
- **Stack**: Next.js 15 App Router + TypeScript + Tailwind CSS
- **DB**: **Supabase (익명 인증)** — 슬로건 *기억* 영속화 — 2026-04-26 도입
- **인증**: Supabase Anonymous Sign-In. sessionStorage는 `anon_user_id` 캐시 용도
- **LLM**: **Google Gemini 3 Flash (`gemini-3-flash`)** — 2026-04-26 Haiku에서 변경
- **스트리밍**: Vercel AI SDK (선제 발화 + 채팅)
- **배포**: Vercel
- **모바일 웹앱** 기준 (max-w-md 단일 컬럼)
