## 슬라이드 6 — 데모 (60초) ★ 가장 중요 — 직접 채우기

### "페어 첫 만남" 60초 시연

1. 인트로 타이핑: *"이야기 속에서만 만나던 캐릭터, 이제 당신의 페어가 되어 곁에 있어요"*
2. 캐릭터 선택 → `[페어링하기]` 버튼 (Pulse 모션)
3. 캐릭터 선제 발화: *"안녕! 오늘 꼭 해야 할 일 하나만 알려줄래?"*
4. 유저 입력 → 캐릭터: *"알았어, 3시간 뒤에 다 했는지 내가 꼭 물어볼게!"*
5. 기분 트래커 → 맞춤 공감

> **이 1분 = 발표의 80% 가치.** 데모 라이브 + 백업 영상 모두 준비.

**비주얼**: 라이브 데모. 안 되면 30초 영상.
