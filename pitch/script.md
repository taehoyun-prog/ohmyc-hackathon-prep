## 04 How it works (60초)

> *"세 노드입니다. 페어 → Memory → Action."*
>
> *"**Pair**: 익명 진입. 세션 ID만으로 시작."*
> *"**Memory**: persistent memory. Supabase에 약속·세션이 누적됩니다."*
> *"**Action**: scheduled action. 시간을 알아서 잡고 챙겨줍니다."*
>
> *"스택은 Next.js 15, Gemini 3 Flash Preview, Supabase, Vercel."*
>
> *"**(슬로건 4번 — 입으로)** 나를 아는 캐릭터가 나를 위해 행동한다."*
>
> *"오픈클로 에이전트 인프라를 소비자향 캐릭터 UX로 래핑합니다. 채팅 LLM이 아니라, 시간·상태·약속을 가진 에이전트."*

**(슬라이드)** 다이어그램 3노드 + 스택 한 줄. 개발자 청자 앵커: `persistent memory` · `scheduled action`.

## 05 Stage 1~3 (60초)

> *"로드맵은 시간이 아니라 기능 단계로 봅니다."*
>
> *"**(슬로건 3번 — 슬라이드에 박힘)** 기억(Memory) + 행동(Action) + 성장(Growth)."*
>
> *"**Stage 1 Memory** — 이번 사이클에서 입증했습니다. 영속화 + 새로고침 비트."*
> *"**Stage 2 Action** — 시간 휴리스틱. '저녁에' 라고 적으면 19시에 챙깁니다."*
> *"**Stage 3 Growth** — 다음 사이클. 대화 누적이 응답을 바꿉니다."*
>
> *"그리고 그 다음 — Stage 4. 캐릭터 마켓플레이스. 누구나 자기 캐릭터를 페어로 띄우는 자리. 오늘은 슬라이드에 안 박았지만, 거기로 갑니다."*

**(슬라이드)** Stage 1·2·3 카드. Stage 4는 입으로만.
